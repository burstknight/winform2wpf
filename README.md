# wf2wpf

**Convert WinForms Designer.cs to WPF XAML with layout inference**

This project provides a Python-based tool to convert WinForms `*.Designer.cs` files to WPF `*.xaml` files by inferring layout intent instead of copying absolute coordinates.

## Language / 語言

- [English](README_EN.md)
- [繁體中文](README_ZH-TW.md)

## Quick Start

```bash
# Sync development environment
uv sync --dev

# Run tests
uv run pytest

# Run CLI
uv run wf2wpf --help
```
